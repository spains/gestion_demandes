# Gestion des Demandes d'Actes Administratifs

API REST + Frontend pour la gestion des demandes d'actes administratifs :
- **Acte de naissance**
- **Casier judiciaire**
- **Certificat de résidence**

Projet réalisé dans le cadre de l'étude de cas **DEP/ASIN 2026** (Développeur junior).

---

## 🛠️ Stack technique

| Couche | Technologie |
|---|---|
| Langage | Java 21 |
| Framework | Spring Boot 3.3.4 |
| Persistance | Spring Data JPA / Hibernate 6 |
| Base de données | MySQL 8 |
| Build | Maven |
| Frontend | HTML5 / CSS3 / JavaScript (Fetch API) |
